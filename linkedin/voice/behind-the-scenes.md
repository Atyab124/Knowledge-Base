# Voice: Behind-the-Scenes

Post: 2 ("I wanted to see if Claude Code could really run unsupervised for 18 hours...") — the only clear example in the source file.

Read [../dos-and-donts.md](../dos-and-donts.md) first — this file only covers what's specific to this category.

> **This one's a first draft, not a settled pattern.** With a single example to work from, treat everything below as a reasonable extrapolation to confirm against future posts, not a confident spec the way the other four voice files are.

## What this category is for

A quick, low-effort process update with no pitch and no lesson attached — proof that work is happening, plus a bit of personality. Distinct from Promoting My Work: there's no knock-then-pivot structure, no numbers-as-evidence, no signature closing line. It's closer to a note to self that happens to be public.

## Shape

1. **State the experiment plainly**, no framing device: *"I wanted to see if Claude Code could really run unsupervised for 18 hours straight on production code."*
2. **Compress the process into shorthand**, almost note-form rather than full sentences: *"Planned out the exact scope of work, exact execution cycle, exact feedback based loops / then incorporated my framework for building production code."*
3. **One small, self-amused joke about a real annoyance**, told flat rather than performed: *"imagine returning to an 'API overload' message / ill build a timer to retry."*
4. **End on a complete non-sequitur, usually a personal aside implying an attached photo**: *"Enjoy this picture of my Mini's lower control arm."* No lesson, no CTA, no signature line — the abrupt personal turn *is* the ending.

## Register

The loosest and least-engineered of any category — lowercase "i," minimal punctuation, fragments rather than sentences. Shorter overall than any other post in the file. Use this register when the point is "still building, here's a glimpse" and nothing is being sold, taught, or argued.

## Checklist

- Is this update genuinely low-stakes — no product claim, no lesson, no argument?
- Did you resist the urge to add a pitch, a lesson, or a closing aphorism? This category earns its casualness by not doing what the other four do.
- Does it end on something unrelated and personal rather than a wrap-up line?
- Before leaning on this file heavily, check whether more Behind-the-Scenes posts have shown up in the source since this was written — one example is a thin base.
