# Miscrits Automation Bot

- What it is: an intelligent automation bot that farms, battles, and trains for the Steam game "Miscrits: World of Creatures" unattended
- Role: solo build
- Stack: Python, PyAutoGUI (input automation), OpenCV template matching, Tesseract OCR + fuzzy string matching for reading in-game text, persistent state across runs
- Notable: OCR reads enemy names and capture percentages live to decide capture-vs-attack; respects in-game cooldowns and timing windows rather than brute-forcing; highest-starred of the smaller repos
- Real numbers: 5 GitHub stars
