# ICM Architect and Van Clief framework map

This package contains two different kinds of material.

1. `icm-architect/` is the current public ICM Architect skill from Jake Van Clief's official GitHub repository. It is pinned to commit `b20fb45063a564cf607b03526e206f519d174def` as retrieved on 2026-08-16. Its MIT license is preserved inside that folder.
2. `frameworks/` is an Ivan-compiled private research map of 48 framework names and short paraphrases. It is a snapshot dated 2026-06-10, not an official Jake Van Clief publication, and it is not guaranteed to be complete or current. Some entries were identified through non-public research sources even though none of those source files or their original text is included.

## What is deliberately excluded

This package does not contain scraped transcripts, paid Clief Notes lesson files, Vault or Drawing Room files, VIP session records, community-member contributions, internal advisor personas, or any Equipt, Vantage, or client applications. The separate framework map contains Ivan's short paraphrases, some of which were informed by that broader research corpus. It must therefore be treated as a private research handoff, not a public or official framework bundle.

## Install the skill

- Claude Code: copy `icm-architect/` to `~/.claude/skills/icm-architect/`.
- Codex: copy `icm-architect/` to `~/.agents/skills/icm-architect/`.
- Keep the folder name `icm-architect` unchanged.

The recipient should read `icm-architect/README.md` and `icm-architect/SKILL.md` before use.

## Provenance note

Ivan's locally installed copy was based on older commit `8f9cdf95e5051f126babc455b7a0558426db43d4` and had one local frontmatter edit adding audit-trigger phrases. This share package uses the newer official upstream copy without that local edit. Upstream remains the source of truth.
